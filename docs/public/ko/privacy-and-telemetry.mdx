Dure는 여러분이 허락하기 전까지 아무것도 보내지 않습니다. 처음 실행하면 메인 창이 익명 사용 데이터를 공유할지 묻고, 답하기 전이나 거절한 뒤에는 어떤 사용 이벤트도 이 기기를 벗어나지 않습니다. 답은 언제든 **설정 → 개인정보 및 텔레메트리**에서 바꿀 수 있습니다.

## 동의하면 보내는 것

이벤트는 [PostHog](https://posthog.com) 미국 클라우드 리전으로 갑니다. 각 이벤트에는 임의의 설치 ID(계정, 이메일, 기기 이름은 절대 아님), 저장되지 않는 실행별 임의 세션 ID, 앱 버전, 릴리스 채널, 운영체제 이름과 버전, CPU 아키텍처가 실립니다. PostHog에는 사람 프로필을 만들지 말고 위치를 조회하지 말도록 지시하며, PostHog 프로젝트는 요청의 IP 주소를 버리도록 설정돼 있습니다.

| 이벤트 | 추가 속성 |
| --- | --- |
| `app_opened` | — |
| `telemetry_accepted`, `telemetry_opted_out` | — |
| `space_created` | — |
| `project_added` | `kind`: `local` 또는 `ssh` |
| `agent_pane_opened` | `provider`: `codex` 같은 코딩 에이전트 ID |
| `message_sent` | `provider` |
| `pane_split` | `direction`: `right` 또는 `below` |
| `pane_hidden`, `pane_restored` | — |
| `quick_dispatch_used` | — |
| `github_panel_opened`, `git_panel_opened`, `ssh_session_opened` | — |

이 목록이 허용 목록 전부입니다. 목록에 없는 이벤트나 속성은 보낼 수 없고, `provider`는 알려진 코딩 에이전트 중 하나입니다. PostHog는 무료 플랜에서 1년, 유료 플랜에서 7년 동안 이벤트를 보관합니다.

## 절대 보내지 않는 것

파일 경로, 저장소·브랜치·워크트리 이름, URL, 커밋 메시지, 프롬프트, 에이전트 출력, 터미널 내용, 오류 메시지, 호스트 이름, 사용자 이름, IP 주소. 이것들을 담을 필드 자체가 없습니다.

## 끄는 방법

- **설정 → 개인정보 및 텔레메트리 → 익명 사용 데이터**: 스위치를 끕니다. Dure는 마지막으로 `telemetry_opted_out` 이벤트 하나를 보내려 시도하고, 설치 ID를 삭제한 뒤 멈춥니다.
- Dure를 실행하는 환경에 `DO_NOT_TRACK=1` 또는 `DURE_TELEMETRY_DISABLED=1`을 설정합니다. 둘 중 하나만 있어도 스위치를 바꾸지 않은 채 우선하며, 설정 페이지가 어느 것이 적용 중인지 알려줍니다.
- CI 환경(`CI`, `GITHUB_ACTIONS`, `GITLAB_CI`, `CIRCLECI`, `TRAVIS`, `BUILDKITE`, `JENKINS_URL`, `TEAMCITY_VERSION`)에서는 절대 보내지 않습니다.

로컬 개발 빌드처럼 텔레메트리 키가 없는 빌드는 질문도 스위치도 보여주지 않고 아무것도 보내지 않습니다.

## 모바일 앱

iPhone과 Android용 Dure 앱은 사용 데이터를 보내지 않습니다. 분석 도구, 오류 보고, 광고 식별자, 계정이 없어서 위의 질문도 하지 않습니다.

- **카메라**: 페어링 QR 코드를 읽을 때만 씁니다. 이미지는 폰 안에서 해독되며 저장하거나 보내지 않습니다.
- **Face ID 또는 지문**: 승인에 답하기 전, 그리고 이 확인을 켜거나 끌 때 본인인지 확인하는 데만 씁니다. 확인은 운영체제가 하고, Dure는 통과했는지만 받습니다.
- **내 컴퓨터**: 세션, 승인, 변경 사항, 커밋은 폰과 페어링한 컴퓨터 사이에서만 오갑니다. 연결에는 그 컴퓨터의 인증서로 고정한 TLS나, 직접 넣은 키를 쓰는 SSH를 씁니다. 페어링 토큰과 SSH 키는 폰의 앱 저장소에 남으며, 기기 백업에 함께 복사될 수 있습니다.
- **릴레이**: 폰이 컴퓨터에 직접 닿지 못하면 연결은 저희가 [Fly.io](https://fly.io)에서 운영하는 Dure 릴레이를 거칩니다. 릴레이는 두 연결을 이어 주기만 합니다. TLS 세션은 폰과 컴퓨터 사이에 맺어지고 릴레이는 컴퓨터의 개인 키를 가진 적이 없으므로, 오가는 내용을 읽을 수 없습니다. 릴레이가 아는 것은 컴퓨터의 서버 ID와 공개 인증서 지문, 양쪽 IP 주소, 연결 시각과 오간 바이트 수입니다. 이 정보는 연결을 잇는 동안 메모리에만 두고 로그로 남기지 않습니다.
- **푸시 알림(iPhone)**: 알림을 켜면 폰이 Apple 푸시 토큰을 페어링한 컴퓨터에 넘기고, 컴퓨터가 이를 저장합니다. 에이전트가 승인을 기다리거나 차례를 마치면 컴퓨터가 그 토큰, 이벤트 종류와 ID, 알림 설정, 앱 언어를 Fly.io의 Dure 푸시 서비스로 보냅니다. 서비스는 "에이전트가 승인을 기다립니다." 같은 정해진 문구를 띄워 달라고 Apple에 요청합니다. 세션 이름, 프롬프트, 에이전트 출력은 알림에 절대 들어가지 않습니다. 서비스는 토큰을 저장하지 않으며, 같은 알림이 두 번 가지 않도록 전송마다 단방향 해시를 1시간 동안만 기억합니다. 알림을 끄면 컴퓨터에서 토큰이 지워집니다.
- **피드백**: **피드백 보내기**는 브라우저에서 GitHub 이슈 양식을 열고 앱 버전과 브라우저 사용자 에이전트를 미리 채웁니다. GitHub에서 양식을 제출하기 전에는 아무것도 보내지 않습니다.

## 문서 사이트

`docs.dureai.dev`는 어떤 페이지가 도움이 되는지 보려고 같은 PostHog 프로젝트로 페이지 조회를 보냅니다. Mintlify의 표준 분석 연동이며, 프로젝트는 요청의 IP 주소를 버리고, 문서 사이트의 어떤 것도 앱의 설치 ID와 연결되지 않습니다.
