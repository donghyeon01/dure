title: "プライバシーと使用データ"
description: "匿名の使用データ共有に同意したとき Dure が送るもの、決して送らないもの、オフにする方法を説明します。"

Dure は、あなたが許可するまで何も送信しません。初回起動時にメインウィンドウが匿名の使用データを共有するか尋ね、答える前や断った後は、使用イベントがこのマシンから出ることはありません。答えはいつでも **設定 → プライバシーとテレメトリー** で変更できます。

## 同意したときに送られるもの

イベントは [PostHog](https://posthog.com) の米国クラウドリージョンに送られます。各イベントには、ランダムなインストール ID（アカウント、メール、デバイス名は決して含まない）、保存されない起動ごとのランダムなセッション ID、アプリのバージョン、リリースチャネル、OS の名前とバージョン、CPU アーキテクチャが付きます。PostHog には人物プロファイルを作らず位置情報を調べないよう指示し、PostHog プロジェクトはリクエストの IP アドレスを破棄するよう設定されています。

| イベント | 追加プロパティ |
| --- | --- |
| `app_opened` | — |
| `telemetry_accepted`, `telemetry_opted_out` | — |
| `space_created` | — |
| `project_added` | `kind`: `local` または `ssh` |
| `agent_pane_opened` | `provider`: `codex` などのコーディングエージェント ID |
| `message_sent` | `provider` |
| `pane_split` | `direction`: `right` または `below` |
| `pane_hidden`, `pane_restored` | — |
| `quick_dispatch_used` | — |
| `github_panel_opened`, `git_panel_opened`, `ssh_session_opened` | — |

この一覧が許可リストのすべてです。一覧にないイベントやプロパティは送信できず、`provider` は既知のコーディングエージェントのいずれかです。PostHog は無料プランで 1 年、有料プランで 7 年間イベントを保持します。

## 決して送らないもの

ファイルパス、リポジトリ・ブランチ・ワークツリー名、URL、コミットメッセージ、プロンプト、エージェントの出力、ターミナルの内容、エラーメッセージ、ホスト名、ユーザー名、IP アドレス。これらを入れるフィールド自体がありません。

## オフにする方法

- **設定 → プライバシーとテレメトリー → 匿名の使用データ**: スイッチをオフにします。Dure は最後に `telemetry_opted_out` イベントを 1 つ送ろうと試み、インストール ID を削除して停止します。
- Dure を起動する環境に `DO_NOT_TRACK=1` または `DURE_TELEMETRY_DISABLED=1` を設定します。どちらか一方でスイッチを変えずに優先され、設定ページがどちらが有効かを示します。
- CI 環境（`CI`、`GITHUB_ACTIONS`、`GITLAB_CI`、`CIRCLECI`、`TRAVIS`、`BUILDKITE`、`JENKINS_URL`、`TEAMCITY_VERSION`）では決して送信しません。

ローカル開発ビルドのようにテレメトリキーのないビルドでは、質問もスイッチも表示されず、何も送信しません。

## モバイルアプリ

iPhone と Android 向けの Dure アプリは使用データを送りません。分析ツール、クラッシュレポート、広告識別子、アカウントがないため、上の質問も表示しません。

- **カメラ**：ペアリング用の QR コードを読むときだけ使います。画像はスマートフォン上で解読され、保存も送信もされません。
- **Face ID または指紋**：承認に答える前と、この確認をオン・オフにするときに、本人であることを確かめるためだけに使います。確認は OS が行い、Dure が受け取るのは成功したかどうかだけです。
- **あなたのコンピューター**：セッション、承認、差分、コミットは、スマートフォンとペアリングしたコンピューターの間だけでやり取りされます。接続には、そのコンピューターの証明書に固定した TLS か、あなたが用意した鍵を使う SSH を使います。ペアリングトークンと SSH 鍵はスマートフォンのアプリ領域に保存され、デバイスのバックアップにコピーされることがあります。
- **リレー**：スマートフォンからコンピューターに直接届かないときは、私たちが [Fly.io](https://fly.io) で運用する Dure リレーを経由します。リレーは 2 つの接続をつなぐだけです。TLS セッションはスマートフォンとコンピューターの間で結ばれ、リレーはコンピューターの秘密鍵を持たないため、流れる内容を読めません。リレーが知るのは、コンピューターのサーバー ID と公開証明書のフィンガープリント、両端の IP アドレス、接続時刻と転送バイト数です。これらは接続をつないでいる間だけメモリに置き、ログには書きません。
- **プッシュ通知（iPhone）**：オンにすると、スマートフォンは Apple のプッシュトークンをペアリングしたコンピューターに渡し、コンピューターがそれを保存します。エージェントが承認を待つかターンを終えると、コンピューターはそのトークン、イベントの種類と ID、通知設定、アプリの言語を Fly.io 上の Dure プッシュサービスに送ります。サービスは「An agent is waiting for your approval.」のような決まった文言を表示するよう Apple に依頼します。セッション名、プロンプト、エージェントの出力が通知に含まれることはありません。サービスはトークンを保存せず、重複通知を防ぐために配信ごとの一方向ハッシュを 1 時間だけ保持します。通知をオフにすると、コンピューターからトークンが削除されます。
- **フィードバック**：**Send feedback** はブラウザーで GitHub の Issue フォームを開き、アプリのバージョンとブラウザーのユーザーエージェントをあらかじめ入力します。GitHub でフォームを送信するまで、何も送られません。

## ドキュメントサイト

`docs.dureai.dev` は、どのページが役立っているかを見るために、同じ PostHog プロジェクトへページビューを送ります。Mintlify の標準的な分析連携であり、プロジェクトはリクエストの IP アドレスを破棄し、ドキュメントサイト上のいかなるものもアプリのインストール ID には結び付きません。

## その他のデータ経路

[診断レポート](/jp/troubleshooting)とアプリ内フィードバックは別のものです。それぞれ送信を押したときだけ送られ、使用データのインストール ID は含まれません。
